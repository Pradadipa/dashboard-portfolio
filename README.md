# Business Dashboard

Dashboard monitoring untuk e-commerce (Shopify + GA4 + Ads + Reviews).

## Stack
- Backend: FastAPI + PostgreSQL (async)
- Frontend: React + TypeScript + Tremor
- Database: PostgreSQL 16

## Structure
- `backend/` — FastAPI application
- `frontend/` — React dashboard
- `db/` — Schema and migrations
- `docs/` — Documentation
